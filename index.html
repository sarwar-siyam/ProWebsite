QuellenCSV · SharePoint · SQL Server
Azure Data FactoryLaden in den Data Lake
Data FlowsAufbereitung → Parquet
Databricks DLTfinale Transformation

–98 %

Aktualisierungszeit von 4 Stunden auf 5 Minuten – täglich automatisch, mit Monitoring und Alerting.

Mein Beitrag

  • Daten aus CSV-Dateien, SharePoint und SQL Server mit Azure Data Factory in den Data Lake geladen.
  • Daten mit Data Flows in die benötigte Form gebracht und als Parquet im Data Lake abgelegt.
  • In Azure Databricks mit Delta Live Tables die finalen Transformationen umgesetzt; Power BI liest nur noch die fertigen Tabellen.
  • Tägliche Aktualisierung automatisiert: ADF-Pipelines mit Triggern, Databricks Jobs und Pipelines, automatische Notebook-Ausführung.
Ausgangslage

Das bestehende Power-BI-Modell verarbeitete alle Abrechnungsdaten selbst. Es war zu langsam geworden: Eine Aktualisierung dauerte rund vier Stunden.

1 Bericht

Mein Beitrag
